# Session 2026-06-13T17:44:36Z

## Goal
Fix the default route (it showed the component-library showcase instead of
login/signup) and make login/signup actually work, in a simple way.

## What I Did
Orientation first: read README/package manifests and traced the auth flow across
frontend and backend. Found three concrete root causes behind "login/signup not
working":

1. **Wrong default route.** `app/page.tsx` rendered the atomic-design component
   showcase. Replaced it with an auth-aware redirect gate: it runs `checkAuth()`
   then `router.replace`s to `/dashboard` (authenticated) or `/login` (not).

2. **Magic-link verify 404.** The backend builds magic links as
   `${FRONTEND_URL}/auth/verify?token=...`, but the verify page lived at
   `app/(auth)/verify/page.tsx`. Route groups are stripped from the URL, so it
   actually served `/verify`, not `/auth/verify` — every magic link 404'd. Moved
   it (git mv) to `app/auth/verify/page.tsx` so the URL matches.

3. **Signup hit a nonexistent endpoint.** The register page + `useAuth.register()`
   POSTed to `/api/auth/register` with name/email/password, but the backend has no
   such route and no password auth at all — auth is magic-link only (send/verify),
   and `sendMagicLink` already auto-creates the user. So signup == login. I
   removed the dead `register()` action and the password `RegisterForm` usage, and
   re-pointed the register page at the magic-link flow by adding a
   `variant: 'login' | 'register'` prop to `LoginForm` (swaps copy only; same
   request). Both `/login` and `/register` now send a magic link.

Also addressed the standing **PR #48 feedback** ("use a logger service on global
level instead of consoles"): added `apps/frontend/lib/logger.ts` (scoped,
level-filtered `createLogger`) and replaced every `console.*` across the frontend
(useAuth, login, register, chat, forms, profile, useTaskStream, page) with it —
~40 call sites. `console` now appears only inside `logger.ts` as the sink.

Dropped the non-functional Google/GitHub social-login placeholder buttons from the
login page (they only `console.log`'d a TODO) to keep the simple email flow honest.
