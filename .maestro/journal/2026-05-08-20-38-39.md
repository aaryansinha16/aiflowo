## What Worked
- Continuing the existing PR #48 branch instead of opening a new PR — the reviewer's feedback is on those exact changes; updating that branch keeps the conversation in one place.
- Picking `createLogger(scope)` per-file over a single global `logger` import — gives every module a stable identity in log output without needing a stack trace.
- Keeping the logger small and synchronous. No transport pipeline, no log buffering, no remote sink wiring. The abstraction is in place; we can layer transports later if/when there's a real need.
- Replacing `token.slice(0, 20)` debug logs with `hasToken: !!token` — even partial JWT prefixes shouldn't be in browser console output.
